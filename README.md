# portfolio-react
My Actual Portfolio (Updated)

Full-stack portfolio and Content Management System (CMS) built with React 19, TypeScript, Vite, Tailwind CSS, DaisyUI, Express.js, MongoDB, and Cloudinary.

## 🚀 Key Platform Features
- **Dynamic Portfolio Showcase**: Multi-dimensional filtering by professional role (with CMS-synchronized badge colors), year (featuring `#00BAFE` brand selection), technology dropdown popover, and real-time keyword search.
- **Blog & News System**: Event recaps, news announcements, and engineering commentary with category filtering, reading time estimates, dynamic category omission, and canonical archive navigation (`/blogs`).
- **Rich TipTap WYSIWYG Editor**: Interactive editor supporting headings, blockquotes, media alignment, multi-item galleries, section title presets, and custom interactive Case Study Embed Cards.
- **Tech Tools Auto-Provisioning & Migration**: Automated synchronization of uncataloged skills into draft Tech Tools with SVG placeholders and private-until-published protection.
- **AI-Powered Portfolio Generator**: OpenAI and Deepseek-powered structured content and descriptions with timeout resilience.
